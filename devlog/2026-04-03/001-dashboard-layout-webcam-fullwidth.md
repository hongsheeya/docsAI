# 대시보드 레이아웃 — 실시간 영상 풀와이드 + 컨트롤 하단 재배치

- **ID**: 001
- **날짜**: 2026-04-03
- **유형**: 기능 추가

## 작업 요약
실시간(웹캠) 모드에서 영상 영역을 전체 폭으로 확대하고, 입력 준비·모델 선택 카드를 영상 아래로 이동시켜 영상 가시성을 크게 개선함. 업로드 모드에서는 기존 2컬럼 레이아웃을 그대로 유지.

## 변경 파일 목록

### view.pug (전면 재작성)
- **레이아웃 분기**: `[ngClass]`로 `inputMode === 'webcam'`일 때 `space-y-6` (1컬럼), 업로드 모드에서 `xl:grid-cols-[minmax(0,1.1fr)_minmax(340px,0.9fr)]` (2컬럼)
- **영상 영역 확대**: 실시간 모드에서 `aspect-[16/9]` + `min-h-[500px]` 적용
- **컨트롤 카드 하단 배치**: 웹캠 모드에서 `grid gap-5 md:grid-cols-2`로 영상 아래 2컬럼 배치
- 기존 bbox 오버레이 캔버스, 실시간 미니 패널 위치 동작 유지
