# 헤더 우측 네비게이션 통일 복구

- **ID**: 005
- **날짜**: 2026-04-16
- **유형**: 버그 수정

## 작업 요약
메인/파이프라인/설명서 페이지 헤더에서 우측 이동 버튼을 제거만 하고 통일된 네비게이션을 넣지 않았던 문제를 수정했다.
메인, 파이프라인, 설명서, 관리자 페이지에 공통 우측 버튼 세트를 다시 배치하고 현재 페이지는 활성 스타일로 구분했다.

## 변경 파일 목록
### 프론트엔드
- `src/app/page.dashboard/view.pug`
  - 헤더 오른쪽에 메인/파이프라인/설명서 버튼과 관리자 조건부 버튼을 추가했다.
- `src/app/page.pipeline/view.pug`
  - 헤더 오른쪽 버튼 구성을 메인/파이프라인/설명서/관리자로 통일했다.
- `src/app/page.manual/view.pug`
  - 설명서 헤더 오른쪽에 동일한 네비게이션 버튼 세트를 추가했다.
- `src/app/page.manual/view.ts`
  - 관리자 버튼 노출용 권한 확인 헬퍼를 추가했다.
- `src/app/page.admin.analysis/view.pug`
  - 관리자 페이지 헤더 오른쪽 버튼 세트를 동일 패턴으로 맞췄다.
