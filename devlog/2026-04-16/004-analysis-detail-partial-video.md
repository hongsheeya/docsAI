# 분석 상세 부분 영상 복원

- **ID**: 004
- **날짜**: 2026-04-16
- **유형**: 버그 수정

## 작업 요약
업로드 분할 로그의 분석 상세 모달에서 부분 영상이 비어 있던 문제를 수정했다.
실시간 로그는 기존 blob 미리보기를 유지하고, 업로드 로그는 원본 분석 영상과 청크 번호를 이용해 서버에서 부분 클립을 생성·스트리밍하도록 연결했다.

## 변경 파일 목록
### 프론트엔드
- `src/app/page.dashboard/view.ts`
  - 분석 상세 모달용 부분 영상 URL, 로딩 상태, 오류 상태를 추가했다.
  - 업로드 로그 상세를 열 때 청크 미리보기 URL을 자동 생성하도록 연결했다.
- `src/app/page.dashboard/view.pug`
  - 분석 상세 모달에서 부분 영상 로딩 문구, 비디오 플레이어, 오류 메시지를 표시하도록 수정했다.

### 백엔드 API
- `src/app/page.dashboard/api.py`
  - 업로드 청크 부분 영상 정보를 조회하고 스트리밍하는 `chunk_preview_info`, `chunk_preview` 엔드포인트를 추가했다.

### 모델/로직
- `src/model/struct/video_analysis.py`
  - 저장된 업로드 분석 메타데이터에서 `chunk_id`를 찾아 부분 영상 클립을 생성하는 `chunk_preview_info()`를 추가했다.
