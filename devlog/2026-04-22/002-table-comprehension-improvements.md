# AI 표 이해도 대폭 개선 (camelot 설치 + 마크다운 표 + 병합 셀 감지)

- **ID**: 002
- **날짜**: 2026-04-22
- **유형**: 기능 개선 + 패키지 설치

## 작업 요약
AI가 표를 제대로 이해하는 데 필요한 4가지 문제를 식별하고 개선했다:
① DOCX 병합 셀 중복값 문제, ② AI 표 표현이 마크다운 형식이 아니었던 문제, ③ 셀별 컨텍스트에 표 위치(마크다운)가 없었던 문제, ④ PDF 표 추출 정밀도 부족. 외부 패키지 camelot-py + ghostscript를 설치하여 PDF 표 처리도 크게 향상했다.

## 변경 파일 목록

### 외부 패키지 설치
- `camelot-py[cv]` 1.0.9: PDF lattice(테두리 있는) 표 정밀 추출. 병합 셀도 올바르게 처리.
- `opencv-python-headless` 4.13.0: camelot cv 의존성
- `ghostscript` (apt): PDF 렌더링용 시스템 패키지 (`/usr/bin/gs`)

### `src/model/struct/file_parser.py`

**① DOCX 병합 셀 dedup** (`parse_docx` 테이블 처리 섹션):
- `id(cell._tc)` 기반으로 같은 tc를 가진 셀은 첫 번째만 값 유지, 나머지는 `''`로 처리
- XML `w:vMerge` 감지로 세로 병합 계속 행의 셀도 빈 칸으로 정확히 표시
- 이전: `| 성명 | 홍길동 | 홍길동 | 홍길동 |` (병합 셀 중복) → 이후: `| 성명 | 홍길동 |  |  |`

**② 마크다운 표 헬퍼 추가** (새 메서드):
- `_table_to_markdown(table, max_rows)`: tables_data → 표준 Markdown 표 변환. AI 모델이 훈련된 형식.
- `_table_to_markdown_with_target(table, row, col, window)`: 특정 셀을 `**[여기에 작성]**` 으로 강조한 주변 행 마크다운 변환

**③ `build_form_description()` 표 섹션 마크다운화**:
- 이전: `행 1: | '헤더1' | '헤더2' | **[빈칸]** |`
- 이후: `| 헤더1 | 헤더2 |` 표준 마크다운 표 (max_rows=25)
- fill items 섹션에서는 context 첫 줄만 사용 (표 전체가 위에 이미 표시되므로 중복 제거)

**④ `_build_table_fill_context()` 위치 마크다운 포함**:
- context에 간단한 위치 요약(첫 줄) + 마크다운 표 스니펫(window=2행) 포함
- 첫 줄: `테이블1 [3행/2열] | 구역: 멘토링 > 열 헤더: 구분 > 행 레이블: 멘토링 구분(전공/외국어) | 기입 규칙: ...`
- 나머지 줄: `| 항목 | 구분 |\n|---|---|\n| ... | **[여기에 작성]** |`

**⑤ `parse_pdf()` camelot 통합**:
- 파일 전체를 camelot `lattice` 모드로 먼저 시도 (테두리 있는 표 고정밀 인식)
- camelot 실패 시 pdfplumber fallback

**⑥ regex 버그 수정** (`_infer_answer_type_from_label`):
- `choice_match` 정규식의 캡처 그룹 `)` 누락 → Python 3.14에서 `re.PatternError` 발생
- `r'[\(\[（【]([^)\]）】]{1,40}[\)\]）】]'` → `r'[(\[（【]([^)\]）】]{1,40})[)\]）】]'` 수정

### `src/model/struct/ai_agent.py`

**`build_context()`**:
- `table_fill_info`: fill 수 20→15개 제한, context 첫 줄(위치 요약)만 사용
- 선택지 choices도 함께 brief 표시: `[규칙: 반드시 선택해 기입 → 전공 / 외국어]`

**`_build_fill_prompt()`**:
- targets 항목별로 context 첫 줄(위치 요약) 표시
- 최초 5개 항목에만 마크다운 표 스니펫 추가 (```블록으로 들여쓰기)
- `form_desc` 표시 한도: 4000→6000자

**`generate_section()` 프롬프트**:
- `form_desc` 표시 한도: 3000→5000자
