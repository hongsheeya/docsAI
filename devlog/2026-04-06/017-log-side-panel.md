# 실시간 분석 로그 사이드 패널 이동

- **ID**: 017
- **날짜**: 2026-04-06
- **유형**: 기능 추가

## 작업 요약
실시간 웹캠 모드에서 분석 로그를 영상 하단에서 오른쪽 사이드 패널로 이동했다. 영상(좌)과 로그(우) 2컬럼 레이아웃으로 변경하여 실시간 모니터링 UX를 개선했다.

## 변경 파일 목록

### view.pug
- 웹캠 모드 레이아웃을 `space-y-6`(수직) → `grid xl:grid-cols-[1fr_380px]`(2컬럼)로 변경
- 컨트롤 영역 div에 `flex flex-col gap-4 min-h-0` 스타일 추가 (웹캠 모드)
- 로그 패널을 컨트롤 영역 내부로 이동 (webcam controls 아래, upload controls 위)
- 로그 패널: `flex-1 min-h-0 overflow-y-auto` → 나머지 공간 채우며 스크롤
- 기존 standalone `section` 로그 리스트 제거 (40줄 삭제)
- 로그 항목을 콤팩트 레이아웃으로 재설계 (text-[12px]→[10px], 간격 축소)
- 반응형: xl 미만에서는 단일 컬럼 폴백
