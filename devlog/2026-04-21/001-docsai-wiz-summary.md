# DocsAI/WIZ 주요 개선 작업 요약 (2026-04-21)

## 1. 표 기반 템플릿 자동 채우기 개선
- 표 구조(반복 행, 예시/샘플 셀, 참조 텍스트 등) 분석 로직 강화
- `_analyze_table_fills`, `_is_fill_candidate_cell`, `_compose_table_fill_label` 등 함수 개선
- 반복 행 그룹, 예시/샘플 셀도 자동 채움 대상에 포함
- DOCX 테이블 셀 직접 쓰기 방식으로 정확도 향상

## 2. 참고 파일 업로드 및 활용 기능 확장
- 참고 파일 업로드: 여러 개 파일, 다양한 포맷 지원
- 업로드된 파일의 텍스트를 추출·집계하여 AI 프롬프트에 포함
- 참고 파일에서 필요한 정보 추출해 자동 채움에 활용

## 3. 인라인 추가 답변 입력 UI/API 구현
- 자동 생성 중 추가 정보 요청 시, AI 채팅 전환 없이 바로 답변 입력 가능
- 답변 입력 UI 및 저장 API(`save_followup_answer`) 추가
- 입력된 답변은 `guide_notes`, `followup_answers`에 반영되어 즉시 활용

## 4. AI 프롬프트 강화 및 비정형 양식 대응
- 필드/섹션 생성 프롬프트에 원본 텍스트, 섹션 제목, 참고 파일 내용 등 최대한 많은 맥락 포함
- "비정형 양식 추론 프로토콜" 도입: 일반적이지 않은 양식도 AI가 구조를 추론해 필요한 정보를 채우도록 유도
- 서두만 생성되는 문제, 텍스트 미삽입 문제 등 해결

## 5. 검증 및 문서화

- devlog.md 및 상세 devlog 파일에 작업 이력 기록
