# 표 기반 양식 채움 정밀화 및 참고자료 다중 업로드 확장

- **ID**: 001
- **날짜**: 2026-04-21
- **유형**: 버그 수정

## 작업 요약
표 구조를 이미 분석하고 있었지만 실제 DOCX 채움 단계가 빈 칸 위주로만 동작해, 예시 텍스트가 들어 있는 셀이나 반복 행 구조를 제대로 채우지 못하던 문제를 보완했다. 또한 참고자료 업로드를 다중 파일 기반으로 확장해 DOCX/PDF/HWP 외 텍스트·CSV류 파일에서도 필요한 정보를 추출해 생성 컨텍스트에 반영하도록 개선했다.

## 변경 파일 목록
### 백엔드
- `src/model/struct/file_parser.py`
  - 반복 행 그룹 인식, 플레이스홀더 셀 판별, 테이블 후보 기반 실제 DOCX 셀 채움 로직 강화
  - 필드명 토큰 매칭 보강으로 표 라벨과 생성 값 연결 정확도 향상
- `src/app/page.doc.write.item/api.py`
  - 참고자료 업로드를 다중 파일로 확장
  - DOCX/PDF/HWP/TXT/MD/JSON/YAML/CSV 텍스트 추출 및 누적 컨텍스트 저장 추가

### 프론트엔드
- `src/app/page.doc.write.item/view.ts`
  - 다중 참고자료 선택/초기화 상태 관리 추가
  - 저장된 참고자료 파일명 목록 로드 추가
- `src/app/page.doc.write.item/view.pug`
  - 다중 파일 선택 UI 및 저장된 참고자료 표시 UI 추가

## 검증
- 변경 파일 진단 오류 없음 확인
- WIZ 프로젝트 일반 빌드 성공 확인
