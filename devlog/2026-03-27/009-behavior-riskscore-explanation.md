# 행동 분류 기준 정리 및 위험점수 설명 추가

- **ID**: 009
- **날짜**: 2026-03-27
- **유형**: 버그 수정

## 작업 요약
최종 낙상 판정이 아닌 경우 행동 분류가 반드시 비낙상으로 표시되도록 기준을 정리했다. 동시에 위험점수가 어떤 방식으로 계산되고 어떤 임계값으로 낙상 여부를 결정하는지 사용자가 바로 이해할 수 있도록 결과 설명을 추가했다.

## 변경 파일 목록
- `src/model/struct/video_analysis.py`
  - 행동 분류를 최종 `fall_detected` 결과에 직접 연동
  - `risk_score_guide`/`behavior_summary` 데이터 추가
  - 판단 근거에 최종 판정 기준 항목 추가
- `src/app/page.dashboard/view.pug`
  - 행동 분류 설명 문구 추가
  - 위험점수 계산 방식 및 판정 기준 표시 추가

## 기대 효과
- 비낙상 결과인데 행동 분류가 낙상으로 보이는 혼란 제거
- 위험점수의 계산 방식과 임계값(현재 0.60)을 결과 화면에서 즉시 확인 가능
