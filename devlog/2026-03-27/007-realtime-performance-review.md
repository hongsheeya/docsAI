# 실시간 분석 성능 종합 검토

- **ID**: 007
- **날짜**: 2026-03-27
- **유형**: 검증 및 문서화

## 작업 요약
RF 파이프라인 최적화와 webm 청크 수정 이후 실시간 분석 성능을 재점검했다. 정상 헤더 webm 청크 기준 서버 분석은 0.42초, 전체 요청은 0.898초로 확인되어 4초 청크/2초 오버랩 구조에서 실시간 운영이 가능한 수준임을 확인했다.

## 측정 결과
- 테스트 입력: 640x480 webm 실시간 청크
- 전체 요청 시간: 0.898s
- 서버 분석 시간: 0.42s
- 사람 검출 프레임: 4프레임
- 행동 분류: `낙상`

## 운영 해석
- 첫 결과 지연: 약 4.9초 (4초 녹화 + 0.9초 처리)
- 이후 갱신 주기: 약 2.9초 이하 (2초 오버랩 기반 새 청크 + 처리시간)
- 백엔드 처리시간이 청크 길이보다 충분히 짧아 대기열 누적 위험이 낮음

## 결론
현재 구성(4초 윈도우, 2초 오버랩, fast profile)은 웹캠 실시간 낙상 감지 MVP 운영에 적합한 수준이다.
