# 추가 데이터 수집 및 모델 고도화 로드맵 분석

- **ID**: 002
- **날짜**: 2026-04-28
- **유형**: 분석 문서

## 작업 요약
연구실 추가 데이터 수집과 이후 모델 고도화의 적용 가능성을 검토했다. 결론적으로 현재 성능 개선에서 가장 ROI가 높은 항목은 **추가 데이터 확보와 hard-case 중심 재구성**이며, 모델 구조 변경보다 먼저 수행하는 것이 타당하다.

## 현재 데이터 전략 기준점
기존 문서에는 최소 목표가 아래처럼 정리돼 있다.

| 클래스 | 목표 |
|--------|------|
| fall | 1000 |
| stand | 300 |
| walk | 500 |
| run | 300 |
| sit | 500 |
| lie | 400 |

또한 hard-case 세트는 아래가 핵심이다.
- `sit-hard`: fast-sit, collapse-sit, offscreen-chair
- `lie-hard`: slow-bed-lie, floor-descend-lie, stretch-lie
- `fall-hard`: kneed-fall, wall-collapse, occluded-fall

이 구성은 현재 운영 이슈와 정확히 연결된다. 최근 운영형 RF-Dual은 FP를 절반 수준으로 줄였지만, sit/lie/occlusion/천천히 눕기 같은 경계 장면에서 아직 trade-off가 크다.

## 개선사항별 적용 여부
### 1. 데이터 추가 수집
- **적용 여부**: 가능, 우선순위 최고
- **판단**: 가장 효과가 크다.
- **이유**:
  - 현재 오탐은 모델 구조의 한계보다 경계 장면 부족의 영향이 크다.
  - sit/lie/walk/fall 경계와 가림 장면은 모델 후처리만으로는 한계가 있다.
  - clip-grouped validation으로 재검증해야 하므로, 양질의 신규 clip이 직접적인 성능 안정화로 이어진다.

### 2. 추가 데이터 확보 후 모델 고도화
- **적용 여부**: 가능
- **판단**: 데이터 수집 직후 반드시 이어져야 한다.
- **이유**:
  - 현재 RF binary, XG-Posture, YOLO 경로 모두 데이터 분포 영향이 큼
  - posture 스크립트는 누수 방지를 위해 grouped CV 기준으로 재검증해야 함
  - 신규 데이터 없이 구조만 바꾸면 현장 일반화 개선폭이 작을 수 있음

## 우선 수집 시나리오 제안
### 1순위 — 오탐 억제 directly 연결
1. 빠르게 앉기 / 주저앉기
2. 천천히 침대에 눕기
3. 바닥에 내려가 눕기
4. 벽/가구를 짚고 내려앉기
5. 화면 일부 가림 상태에서의 전이 동작

### 2순위 — 운영 환경 일반화
1. 카메라 각도 변화 (정면/측면/대각)
2. 거리 변화 (근거리/중거리/원거리)
3. 조도 변화 (주간/야간/역광)
4. 침대, 휠체어, 보행기, 의자 주변
5. 1인/복수 인원, 배경 움직임 포함 장면

### 3순위 — posture 분리 개선
1. stand ↔ sit 전이
2. walk ↔ run 경계
3. lie ↔ fall 경계
4. 짧은 클립 / 부분 동작 클립

## ROI 기준 우선순위
| 수집 유형 | 기대 효과 | ROI |
|-----------|----------|-----|
| sit/lie hard-case | FP 감소에 직접적 | 매우 높음 |
| occluded-fall / partial visibility | FN/FP 둘 다 개선 | 높음 |
| 침대/의자/보행기 주변 | 병원/요양 환경 일반화 | 높음 |
| walk/run 추가 | posture 품질 개선 | 중간 |
| run 대량 추가 | 낙상 탐지 직접효과는 제한적 | 중간 이하 |

## 모델별 기대 개선 효과
### RF binary
- 신규 hard-case와 실제 환경 데이터가 가장 직접적으로 반영된다.
- 기대 효과:
  - FP 감소 폭이 가장 먼저 나타날 가능성
  - guard 의존도를 일부 줄일 수 있음
  - Recall을 덜 희생하고 FP를 억제할 여지 증가

### XG-Posture
- class 불균형과 전이 구간 라벨 품질 영향을 크게 받는다.
- 기대 효과:
  - sit/lie/stand/walk 구분 안정화
  - arbitration 입력 품질 향상
  - fall vs non-fall 보조 판단 정확도 향상

### YOLO detect/pose
- 데이터 추가가 직접적 성능 향상으로 이어질 수도 있지만, 현재 detector 자체는 이미 성능이 나쁘지 않다.
- 기대 효과:
  - 병원/실내/가림 특화 장면에서 detection 안정성 향상
  - keypoint 품질 개선으로 posture downstream 보조

## 예상 성능(보수적 추정)
> 아래 수치는 로그와 현재 오류 패턴을 바탕으로 한 운영 추정치이며, 실제 값은 신규 데이터 품질과 검증 프로토콜에 따라 달라진다.

### 1단계 — 기존 N 재라벨링 + hard-case 세트 구축
- 기대 효과:
  - FP 상대 15~30% 감소
  - Recall 변화는 작거나 소폭 개선
  - posture 혼동 케이스 리포트 품질 향상

### 2단계 — 연구실 controlled 수집 200~500 clip 추가
- 기대 효과:
  - 경계 장면에서 FP 상대 30~50% 감소 가능성
  - 현재 guard로 희생된 Recall 2~5%p 회복 가능성
  - 운영 threshold를 더 완만하게 조정할 근거 확보

### 3단계 — 환경 다양성 포함한 대규모 추가 수집
- 기대 효과:
  - 현장 일반화 성능의 안정적 상승
  - 모델 교체 없이도 F1, calibration, false alarm rate 전반 개선 가능

## 권장 고도화 순서
1. 기존 `N` 영상 재라벨링 및 hard-case 별도 태깅
2. 연구실 controlled 데이터 수집
3. clip-grouped validation 세트 재구성
4. RF binary 재학습
5. XG-Posture 재학습
6. threshold / guard 재튜닝
7. 운영 shadow test 후 반영

## 최종 판단
- **즉시 가능한 부분**: 기존 데이터 재라벨링, hard-case 구축, 연구실 수집 프로토콜 정리
- **가장 효과 큰 부분**: sit/lie/occlusion 중심 hard-case 확보
- **예상 성능**: 데이터 품질이 확보되면 현재 운영 대비 FP는 유의미하게 감소하고, guard로 잃은 Recall 일부 회복 가능성이 높음
- **권장 방향**: 모델 교체보다 데이터 전략 선행
