# 실시간 모드 RF 구조 분석 및 개선 방안 설계

- **ID**: 006
- **날짜**: 2026-04-02
- **유형**: 분석·설계

## 작업 요약
1. 실시간 모드 전체 아키텍처 분석 (듀얼 MediaRecorder 4초 청크 → 업로드 API 재사용)
2. 학습 데이터 v4 feature 분포 vs 4초 청크 feature 비교 분석 (n_frames 2.6% overlap)
3. 4가지 개선 방안 비교 (보정/정규화/서브샘플링/슬라이딩윈도우)
4. "방안 A(즉시 보정) + 방안 D(장기 슬라이딩윈도우)" 조합 채택

## 핵심 발견사항
- 학습 데이터(998건) 중 n_frames ≤ 8인 샘플은 2.6%(26건)뿐
- 4초 청크의 예상 n_frames = 6~8 → 모델 결정 경계의 극단값
- 가장 중요한 feature(final_height_ratio, 22.6%)가 3프레임 고정 tail → 8프레임 중 37.5% 차지
- Motion guard 임계값이 짧은 클립에서 과도한 억제 가능
