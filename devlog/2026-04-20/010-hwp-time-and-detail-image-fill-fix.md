# HWP 시간 필드 파싱 및 세부활동 내용+이미지 병행 삽입 수정

- **ID**: 010
- **날짜**: 2026-04-20
- **유형**: 버그 수정

## 작업 요약
사진을 배치하면 HWP/PDF 미리보기에서 `세부 활동 내용` 본문이 사라지고, `활동 시간`이 `00`으로 남는 문제를 수정했다.
원인은 HWP 셀 채움 로직이 이미지가 있는 행에서 텍스트 채움을 건너뛰고 있었고, 섹션 파싱이 시간 문자열의 `:`를 잘못 라벨 구분자로 해석하고 있었기 때문이다. 또한 Struct 하위 모듈 캐시로 인해 수정 코드가 즉시 반영되지 않던 문제를 해결하기 위해 동적 fresh-loading 경로를 추가했다.

## 변경 파일 목록

### Backend — Model/Struct
- `src/model/struct/doc_export.py`
  - 섹션 필드 파싱에서 `활동 시간 : 2026년 ... 19:00 ~ 21:00` 형태를 올바르게 읽도록 첫 번째 콜론 기준 파싱으로 수정
  - 이미지가 배치된 셀에서도 실제 본문 텍스트를 먼저 채운 뒤 이미지를 아래에 삽입하도록 로직 수정
  - `[사진 첨부 영역]`, 파일명 bullet 같은 첨부 마커 텍스트를 실제 이미지 삽입 시 제거하도록 정리
  - `00`, `00:00 ~ 00:00`, 날짜 placeholder 같은 값도 빈칸 placeholder로 인식하도록 확장
  - 본문 길이에 따라 이미지 최대 높이를 자동 조절하도록 개선
- `src/model/struct/ai_agent.py`
  - 필드/섹션/채팅 프롬프트에 사진이 있어도 본문 서술을 줄이거나 대체하지 말라는 규칙 추가
- `src/model/struct.py`
  - `file_parser`, `ai_agent`, `doc_export`, `graph_gen`를 fresh-loading 하도록 바꿔 Python sub-struct 캐시를 우회

### 검증
- `preview_html`에서 `활동 시간`이 `2026년 4월 7일 화요일 19:00 ~ 21:00`으로 채워지는 것 확인
- `세부 활동 내용` 본문과 `data:image`가 함께 존재하고, 기존 placeholder 문구가 제거된 것 확인
- 이미지 스타일이 `max-height:60mm` 및 `object-fit:contain`으로 반영된 것 확인
- 일반 빌드 및 클린 빌드 성공 확인
