# 서기/앉기 무릎 각도 보정 수정

- **ID**: 001
- **날짜**: 2026-04-20
- **유형**: 버그 수정

## 작업 요약
XG-Posture 후처리에서 `pose_knee_bend_mean` 값을 정규화 비율처럼 해석하던 버그를 수정했다. 실제 값은 무릎 각도(도)인데 `0.25`, `0.24` 같은 임계값으로 비교하고 있어, 하체가 보이기만 하면 거의 항상 앉기 쪽 부스트가 걸리던 문제가 있었다. 이를 실제 각도 기준으로 교체하고, 하체 가시성/무릎 펴짐 비율을 추가해 무릎이 펴진 경우 서기로 되돌리는 보정 규칙을 넣었다.

## 변경 파일 목록
- `src/model/struct/video_analysis.py`
  - 하체 가시성(`lower_body_visibility`), 무릎 펴짐 비율(`straight_leg_ratio`), 무릎 굽힘 비율(`bent_leg_ratio`) 특징 추가
  - `sit -> stand` 구조 보정 규칙 추가
  - `stand -> sit`, `lie -> sit` 보정에서 잘못된 무릎 임계값을 실제 각도 기준으로 수정

## 기대 효과
- 하체가 보이고 무릎이 펴진 장면을 앉기로 과대판정하던 현상 완화
- 앉기 판정은 실제로 다리가 굽은 경우에 더 강하게만 적용
- 눕기/앉기 경계에서도 무릎 정보가 제대로 작동하도록 개선
