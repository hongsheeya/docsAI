# FallAI GitHub 코드 읽는 법

이 문서는 교수님처럼 프로그래밍을 전공하지 않은 검토자가 GitHub에서 FallAI 코드를 읽을 때 길을 잃지 않도록 만든 안내문입니다.

## 1. 접속 주소

전체 코드 브랜치:

https://github.com/hongsheeya/docsAI/tree/fallai-full-code

GitHub 화면에서 `fallai-full-code` 브랜치가 선택되어 있어야 최신 FallAI 코드와 설명 문서를 볼 수 있습니다.

## 2. 가장 먼저 볼 파일

1. `README.md`
   - 프로젝트 표지입니다.
   - FallAI가 무엇을 하는 사이트인지, 주요 기능과 폴더 구조가 요약되어 있습니다.

2. `docs/professor-code-overview-20260629.md`
   - 비전공자용 전체 설명 문서입니다.
   - 화면, 서버, AI 모델, 학습 스크립트가 어떤 역할을 하는지 쉬운 말로 정리했습니다.

3. `docs/code-explorer/README.md`
   - 코드 탐색 페이지 사용법입니다.

4. `docs/code-explorer/index.html`
   - 원본 코드 전체와 쉬운 설명을 함께 볼 수 있는 코드 탐색 페이지입니다.
   - 왼쪽에는 파일 목록, 가운데에는 실제 코드, 코드 옆에는 줄별 쉬운 해석, 오른쪽에는 파일 설명과 주요 함수 위치가 들어 있습니다.
   - GitHub 화면에서는 HTML 파일의 원문이 보일 수 있으므로, 실제 탐색 화면으로 보려면 파일을 내려받아 브라우저에서 열면 됩니다.

5. `docs/server-restore-guide-20260629.md`
   - 회사 서버가 닫히거나 다른 서버로 옮겨야 할 때 복구하는 절차입니다.

## 3. GitHub 화면에서 누르는 순서

1. 위 GitHub 주소에 접속합니다.
2. 화면 왼쪽 위나 파일 목록 위쪽에 브랜치명이 `fallai-full-code`인지 확인합니다.
3. `README.md`를 먼저 읽습니다.
4. `docs` 폴더를 누릅니다.
5. `professor-code-overview-20260629.md`를 읽습니다.
6. 더 자세히 코드와 설명을 같이 보고 싶으면 `docs/code-explorer/index.html`을 엽니다.
7. 특정 기능이 궁금하면 아래 폴더 설명에 맞춰 이동합니다.

## 4. 주요 폴더를 쉬운 말로 설명

| 폴더 | 쉬운 설명 |
| --- | --- |
| `src/app/` | 사용자가 브라우저에서 보는 화면입니다. 버튼, 카드, 표, 영상 영역이 들어 있습니다. |
| `src/app/page.dashboard/` | 영상 업로드, 웹캠 분석, 사람별 카드, 낙상/행동/표정 결과를 보여주는 메인 화면입니다. |
| `src/app/page.models/` | 모델 버전, 성능, 백그라운드 학습 상태를 관리하는 화면입니다. |
| `src/app/page.pipeline/` | 프레임 처리, RTT, 다중 인원, 4카메라 시뮬레이션 같은 분석 흐름을 설명하는 화면입니다. |
| `src/model/` | 서버 쪽 핵심 기능입니다. 영상 분석, 사용자 처리, 데이터 처리가 들어 있습니다. |
| `src/model/struct/video_analysis.py` | FallAI의 가장 중요한 AI 분석 로직입니다. 사람 감지, 낙상, 행동, 표정/상태 보조 분석을 묶어 처리합니다. |
| `src/model/libs/` | 모델 학습과 판단을 돕는 보조 코드입니다. |
| `scripts/` | 학습, 평가, 성능 테스트, 보고서 생성을 실행하는 도구입니다. |
| `docs/` | 실험 결과, 복구 가이드, 교수님용 설명 문서입니다. |
| `config/` | WIZ 프로젝트 실행 설정입니다. |

## 5. 파일 확장자 읽는 법

| 확장자 | 뜻 |
| --- | --- |
| `.py` | Python 코드입니다. 서버 처리, AI 분석, 학습 스크립트에 사용됩니다. |
| `.ts` | TypeScript 코드입니다. 화면에서 버튼을 눌렀을 때의 동작을 담당합니다. |
| `.pug` | 화면 구조 파일입니다. 어떤 버튼과 카드가 어디에 놓이는지 정합니다. |
| `.scss` | 화면 디자인 파일입니다. 색상, 간격, 크기, 반응형 레이아웃을 정합니다. |
| `.json` | 설정값을 정해진 형식으로 저장한 파일입니다. |
| `.md` | 사람이 읽는 설명 문서입니다. |

## 6. “코드 전체”에서 제외한 항목

다음 항목은 GitHub에 올리지 않는 것이 정상입니다.

| 제외 항목 | 제외 이유 |
| --- | --- |
| AI-Hub 원본 데이터 | 용량이 크고 라이선스/개인정보 문제가 있을 수 있습니다. |
| 업로드 영상 | 개인정보가 포함될 수 있습니다. |
| 학습된 모델 가중치 | 용량이 크고 GitHub 관리에 적합하지 않습니다. |
| `node_modules/` | 외부 라이브러리 설치 폴더라 직접 작성한 코드가 아닙니다. |
| `storage/`, `outputs/`, `data/` | 실행 중 생기는 저장 데이터와 결과물입니다. |
| 토큰, 비밀번호, API 키 | 보안상 절대 올리면 안 됩니다. |

따라서 GitHub에는 “사이트를 구성하는 코드와 설명 문서”를 올리고, 대용량 데이터와 모델 파일은 별도 백업으로 보관하는 방식이 맞습니다.

## 7. 코드 흐름을 한눈에 보는 방법

FallAI는 다음 순서로 동작합니다.

```text
사용자 브라우저
  ↓
src/app/ 화면 코드
  ↓
src/app/.../api.py 서버 API
  ↓
src/model/struct/video_analysis.py AI 분석 로직
  ↓
src/model/libs/ 모델 보조 로직
  ↓
분석 결과가 다시 화면 카드와 그래프로 표시됨
```

즉, 화면은 `src/app/`, 실제 분석은 `src/model/`, 학습과 실험은 `scripts/`, 설명과 보고서는 `docs/`에서 보면 됩니다.

## 8. 교수님께 전달할 짧은 설명문

아래 문장을 그대로 전달해도 됩니다.

> FallAI 전체 코드는 GitHub의 `fallai-full-code` 브랜치에 정리되어 있습니다. `README.md`가 표지이고, `docs/professor-code-overview-20260629.md`에는 비전공자용 전체 설명이 있습니다. 실제 코드와 쉬운 설명을 함께 보려면 `docs/code-explorer/index.html`을 내려받아 브라우저에서 열면 됩니다. 보안과 용량 문제 때문에 AI-Hub 원본 데이터, 업로드 영상, 모델 가중치, 토큰/비밀번호는 GitHub에서 제외했고, 사이트 코드와 설명 문서는 확인할 수 있게 올려두었습니다.
