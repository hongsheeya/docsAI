# 행동분석 데이터 수집 라벨 안내

행동분석 및 낙상 판단 보조 시스템의 학습 데이터를 새로 만들 때 사용할 라벨과 기존에 사용한 데이터셋을 정리한 공지용 문서입니다.

## 1. 수집 대상 라벨

현재 시스템에서 사용한 행동/상태 라벨은 크게 두 종류입니다.

### 1.1 낙상 여부 라벨

| 라벨 | 의미 |
|---|---|
| `fall` | 낙상 |
| `non-fall` | 비낙상 |

시스템 내부 학습 데이터에서는 다음처럼 저장됩니다.

| 내부 라벨 | 의미 |
|---|---|
| `Y` | 낙상 영상 |
| `N` | 비낙상 영상 |

### 1.2 행동/자세 라벨

행동분류 모델은 아래 5개 동작을 기준으로 학습했습니다.

| 라벨 | 의미 |
|---|---|
| `stand` | 서기 |
| `walk` | 걷기 |
| `run` | 뛰기 |
| `sit` | 앉기 |
| `lie` | 눕기 |

## 2. 영상별 기록 권장 항목

데이터셋을 새로 만들 때는 영상마다 아래 정보를 함께 기록하는 것이 좋습니다.

| 항목 | 권장 값 |
|---|---|
| 낙상 여부 | `fall` / `non-fall` |
| 행동/자세 | `stand` / `walk` / `run` / `sit` / `lie` |
| 하체 가림 여부 | 있음 / 없음 |
| 애매한 장면 여부 | 있음 / 없음 |
| 짧은 클립 여부 | 있음 / 없음 |
| 촬영 환경 | 침대, 의자, 바닥, 복도, 실내 등 |
| 카메라 조건 | 정면, 측면, 위쪽, 일부 가림 등 |

## 3. 우선 수집이 필요한 장면

추가 수집이 특히 필요한 장면은 다음과 같습니다.

- 앉기와 눕기 경계 장면
- 서 있다가 천천히 앉는 장면
- 침대나 의자에서 자세가 무너지는 장면
- 하체가 가려진 상태에서 서기/앉기/눕기
- 걷기와 뛰기처럼 속도 차이가 애매한 장면
- 낙상 직전/직후가 4초 구간 경계에 걸리는 장면

현재 시스템은 영상을 `4초 창 / 2초 stride`로 중첩 분석합니다. 따라서 낙상이나 자세 변화가 짧게 발생하는 장면은 앞뒤 맥락이 함께 보이도록 충분한 길이로 촬영하는 것이 좋습니다.

## 4. 사용한 데이터셋 정리

### 4.1 낙상 판단 데이터

| 항목 | 내용 |
|---|---|
| 데이터셋 | AI-Hub 71641 계열 낙상/비낙상 데이터 |
| 경로 | `/opt/app/datasets/fall_classification/aihubs_71641` |
| 목적 | `fall` / `non-fall` 이진 분류 |
| 현재 학습 샘플 | 1,592개 |
| 클래스 분포 | `non-fall` 795 / `fall` 797 |
| 사용 모델 | RF-Fall v2 occlusion-aware |

### 4.2 행동/자세 분류 데이터

| 데이터셋 | 경로 | 역할 |
|---|---|---|
| AI-Hub 71461 행동 분류 데이터 | `/opt/app/datasets/action_behavior/aihub_71461` | 서기, 앉기, 눕기 등 행동 라벨 보강 |
| AI-Hub 61 사람동작 2020 | `/opt/app/datasets/action_behavior/aihub_61_person_action_2020` | 걷기, 뛰기, 앉기, 눕기 sequence 보강 |

| 항목 | 내용 |
|---|---|
| 목적 | `stand` / `walk` / `run` / `sit` / `lie` 5-class 행동분류 |
| 현재 학습 windows | 8,181개 |
| 사용 모델 | XG-Posture 5-class |

클래스 분포는 다음과 같습니다.

| 클래스 | 샘플 수 |
|---|---:|
| `stand` | 725 |
| `walk` | 1,664 |
| `run` | 1,664 |
| `sit` | 2,244 |
| `lie` | 1,884 |

### 4.3 하체 가림 보조 데이터

| 항목 | 내용 |
|---|---|
| 원천 | XG-Posture 행동/자세 데이터 |
| 방식 | synthetic occlusion 생성 |
| 목적 | 하체가 침대, 가구, 화면 밖 등으로 가려졌을 때 `stand` / `sit` / `lie` 혼동 감소 |
| 사용 모델 | XG-Posture occlusion auxiliary |

가림 방식은 다음과 같습니다.

- 허리 아래 가림
- 허벅지 아래 가림
- 무릎 아래 가림
- 좌측/우측 세로 가림

### 4.4 보조 상태 데이터

행동분석의 핵심 라벨은 아니지만, 시스템 보조 근거로 사용했습니다.

| 데이터셋 | 경로 | 역할 |
|---|---|---|
| AI-Hub 82 한국인 감정 데이터 | `/opt/app/datasets/facial_state/aihub_82_korean_emotion` | 불안, 슬픔, 상처, 중립 등 표정 보조 |
| AI-Hub 173 운전자 상태 데이터 | `/opt/app/datasets/facial_state/aihub_173_driver_state` | 졸림, 하품, 주의저하 등 상태 보조 |

표정/상태 데이터는 낙상 판단의 직접 라벨이 아니라 보조 근거로만 사용합니다.
