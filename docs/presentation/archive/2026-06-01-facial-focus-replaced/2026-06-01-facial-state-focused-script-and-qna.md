# FallAI 표정/상태 보조 모델 발표 대본 및 예상 질문

- 생성: 2026-06-01 00:55 UTC
- 발표 톤: 표정 모델이 낙상을 직접 판단한다는 식으로 과장하지 않는다.

## 발표 대본

### 슬라이드 1
이번 발표는 표정/상태 보조 모델 위주로 정리했습니다. 결론부터 말하면 표정 모델은 낙상 모델을 대체하지 않고, 낙상 판단의 설명 근거를 보강하는 역할입니다.

### 슬라이드 2
교수님 요청은 표정이나 상태를 보고 낙상 전 위험 신호를 볼 수 있느냐였습니다. 그래서 일반 감정 모델과 상태 모델을 따로 붙였고, 얼굴이 안 보이면 절대 불안이나 위험으로 기본 처리하지 않도록 바꿨습니다.

### 슬라이드 3
데이터는 AI-Hub 82 한국인 감정 데이터와 AI-Hub 173 상태 데이터를 사용했습니다. 82는 7개 감정, 173은 정상주시, 졸음, 하품, 통화, 흡연 같은 상태 라벨입니다.

### 슬라이드 4
성능은 82가 macro F1 0.6198로 아직 보조 근거 수준이고, 173은 macro F1 0.9054로 상태 분류는 비교적 안정적입니다. 그래서 두 모델의 역할도 다르게 잡았습니다.

### 슬라이드 5
런타임에서는 먼저 얼굴이 실제로 보이는지 확인합니다. 얼굴 검출이 안 되거나 신뢰도가 낮으면 표정 결과를 만들지 않고 '얼굴/표정 미검출'로 표시합니다.

### 슬라이드 6
낙상 판단은 여전히 RF-Fall v2가 먼저 합니다. 표정은 사람이 고통스러워 보이는지, 졸림이나 주의저하 상태인지 같은 보조 evidence로만 붙습니다.

### 슬라이드 7
이 방식의 한계도 분명합니다. 낙상 순간에는 얼굴이 바닥이나 팔에 가려질 수 있고, 일반 감정 데이터가 실제 통증 표정을 완전히 대표하지 못합니다.

### 슬라이드 8
다음 단계는 실제 설치 각도에서 얼굴이 작게 보이거나 가려진 데이터를 모으고, 71785 안면 랜드마크를 이용해 얼굴 ROI 품질을 보정하는 것입니다.

### 슬라이드 9
마지막으로 SHAP는 모델을 새로 학습하는 방식이 아니라, RF/XGBoost가 어떤 feature 때문에 판단했는지 설명하는 도구입니다. 이걸 표정 evidence와 함께 묶으면 LLM 설명 근거를 더 투명하게 만들 수 있습니다.

## 예상 질문

### Q1. 표정만 보고 낙상 예측이 가능한가요?
불가능에 가깝습니다. 얼굴은 가려질 수 있고, 표정과 낙상 사이에는 직접 인과가 약합니다. 현재는 낙상 판단 보조 근거로만 사용합니다.

### Q2. 왜 AI-Hub 82 성능이 낮은데 사용하나요?
82는 일반 감정 데이터라 낙상 특화가 아닙니다. 그래서 최종 판단 모델로 쓰지 않고, 얼굴이 보이고 신뢰도가 충분할 때만 약한 보조 evidence로 씁니다.

### Q3. 173 모델은 운전자 상태인데 낙상 시스템에 왜 쓰나요?
졸림, 하품, 주의저하 같은 상태 신호는 직접 낙상 라벨은 아니지만 위험 상태 설명에는 도움이 됩니다. 단, 도메인 차이가 있으므로 보조 근거로만 제한합니다.

### Q4. RTT가 늘어난 문제는 해결됐나요?
표정 모델을 매 프레임 무겁게 돌리지 않고 얼굴 품질 gate, 낮은 cadence, 캐시/비동기 evidence 중심으로 줄이는 방향으로 정리했습니다. 계속 측정이 필요합니다.

### Q5. 다음 데이터는 무엇이 가장 필요하나요?
실제 설치 각도에서 얼굴이 작거나 가려진 낙상 전후 영상, 누운 자세 얼굴, 조명 변화, 고령자 표정/통증 상태 데이터가 가장 필요합니다.
